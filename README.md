# BOSS 直聘 · 定向自动沟通助手

> **求职端（非招聘端）** 浏览器扩展：在 BOSS 直聘网页版按关键词 / 屏蔽词 / 公司 / 地区筛选岗位，自动逐个进入职位详情发起沟通、在聊天页发送自定义招呼语，发送完自动回到你开始时的**职位方向与城市**继续下一个。

仅用于个人求职，模拟真人点击流程，内置随机延迟与跨会话去重，降低风控风险。**请勿高频使用，账号安全与使用后果由使用者自行承担。**

---

## 功能特性

- **关键词筛选**：职位名称需包含任一关键词才处理（中英文逗号均可，不区分大小写）
- **屏蔽关键词职务**：职位名称含任一屏蔽词即跳过（默认：外包、驻场、外派、资深、高级、实习、应届）
- **屏蔽指定公司**：公司名含任一关键词即跳过
- **限定地区（只投你选的城市）**：在面板填城市（如 `珠海`）后，点「开始」会**自动打开顶部城市选择弹窗、按拼音分组定位并真正选中该城市**，让列表只加载该城市职位；留空则按「页面顶部所选城市 → 方向名括号里的城市（如 `Java(珠海)`）」锁定。锁定后只与该城市岗位沟通，自动跳过混排进来的外地岗位（广州 / 深圳 / 佛山等），发送与刷新后城市都不会丢
- **记录职位方向 tab**：点「开始」时识别并记录顶部所处方向（推荐 / 大模型算法(珠海) / Java(珠海) / Android(珠海) 等求职期望），发送返回后自动切回该方向，不会再掉回默认「推荐」页
- **开始即全量加载**：点「开始」并选好城市后，先自动持续下滑把该城市 / 方向职位全部加载出来（方向页最多约 450 个），边加载边把符合条件的岗位增量入队，再逐个沟通
- **投完自动整页刷新凑满本轮上限**：本批岗位全部投完仍未达到「本轮上限」时，自动整页刷新、重新全量加载并**跨会话去重只投新岗位**；连续 2 轮刷新都没有新岗位可投才停止（城市 / 方向筛选条件保持不变）
- **自定义招呼语**：支持 `{jobName}` `{company}` `{salary}` 占位符，自动替换为当前岗位信息
- **自动去重**：已发送的岗位跨会话记录，不会重复沟通
- **随机间隔**：每个岗位之间随机等待，可配置最小 / 最大秒数（最低 1 秒）
- **本轮上限**：可设置单次运行最多沟通多少个岗位
- **配置本地保存**：面板输入实时存入浏览器，关闭重开不丢失
- **日志面板**：保留最近 20 行运行日志，便于排查

## 安装方法（Edge / Chrome）

本项目为 Manifest V3 浏览器扩展，以「加载解压缩的扩展」方式安装，无需上架商店。

### Edge

1. 打开 Edge，地址栏输入 `edge://extensions` 回车
2. 左下角打开「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择本项目下的 **`extension`** 文件夹（包含 `manifest.json` 的那一层）
5. 扩展出现在列表中即安装成功；后续更新代码后在该卡片点「重新加载」

### Chrome

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目下的 **`extension`** 文件夹

## 使用方法

1. **登录 BOSS 直聘**网页版（`https://www.zhipin.com`）
2. **选好职位方向与城市**（二选一即可，脚本都会记录）：
   - **方式 A（推荐，职位更多）**：在首页顶部点选你的求职期望方向 tab，如 `Java(珠海)`、`大模型算法(珠海)`（方向页一个方向最多可加载约 450 个职位）；
   - **方式 B**：在顶部搜索框搜索职位关键词、选好城市，进入搜索结果列表页。
   - 页面右下角会出现「BOSS 自动沟通助手」悬浮面板。
3. 在面板中配置：
   - **关键词**：职位名称需包含的词，逗号分隔（中英文逗号均可）
   - **屏蔽关键词**：不想投的职位类型
   - **屏蔽公司**：不想投的公司
   - **限定地区**：**留空即可自动锁定你选的城市 / 方向名括号里的城市**；也可手动填，如 `珠海` 或 `珠海,中山`
   - **招呼语**：要发送的内容，可用占位符
   - **本轮上限**：本次最多沟通多少个
   - **间隔**：每个岗位之间随机等待秒数（建议不要低于 1~2 秒）
4. 点击「开始」，脚本自动运行：
   - 记录当前方向 tab 与城市 → 扫描当前已加载职位并筛选 → 逐个进入详情 → 点「立即沟通」→ 聊天页自动填写并发送招呼语 → 自动切回原方向 → 处理下一个；当前职位投完后自动下滑加载更多，直到本轮上限或没有新职位
5. 可随时点「暂停」或「停止」

> 提示：
> - 方向页（推荐 / 求职期望 tab）是平台的**全国推荐流**，一个方向最多可加载约 450 个，但会混入大量质检、销售、普工等与技术关键词无关、以及外地的岗位，脚本会按关键词 + 城市自动过滤。
> - 用面板「限定地区」让脚本在城市选择器选中城市后，落到的是该城市的**城市综合流**（`jobs?city=城市码`，不含职位关键词），职位数量通常较少且更杂（不少城市只有十几个到几十个）。**想要尽量多的某城市技术岗，建议先在顶部搜索框输入关键词（如 `java`）并选好城市，进入城市搜索结果页（`jobs?city=城市码&query=关键词`）再点开始**，脚本选中城市时也会保留你 URL 里的关键词。
> - 综上，**某城市某方向实际可投的岗位可能远少于 450 或你设置的本轮上限**（例如珠海的大模型 / Java 技术岗往往只有几个到十几个），这是平台岗位存量决定的；脚本刷到连续 2 轮无新岗位即停止，属正常现象，并非脚本漏投。

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 关键词 | 职位名称含任一即匹配，中英文逗号均可 | `java` |
| 屏蔽关键词 | 职位名称含任一即跳过 | `外包,驻场,外派,资深,高级,实习,应届` |
| 屏蔽公司 | 公司名含任一即跳过 | 空 |
| 限定地区 | 只投这些城市；留空 = 自动锁定页面 / 方向所选城市 | 空（自动） |
| 招呼语 | 支持 `{jobName}` `{company}` `{salary}` | 见下 |
| 本轮上限 | 单次运行最多沟通数 | 30 |
| 最小间隔 | 岗位间最小等待秒数（≥1） | 8 |
| 最大间隔 | 岗位间最大等待秒数 | 15 |

**默认招呼语**：
```
您好！我看到贵司在招 {jobName}，我对这个岗位非常感兴趣，有相关的项目经验，希望有机会和您进一步沟通。
```

**占位符说明**：
- `{jobName}` → 当前职位名称（如「Java开发工程师」）
- `{company}` → 公司名称
- `{salary}` → 薪资范围

> 关键词按「子串」匹配，像「开发」「软件」「ai」这类较宽的词可能匹配到「业务开发专员」「客户开发」等销售岗，建议配合更精确的词（如 `java,android,后端,算法`）并善用屏蔽词。

## 工作流程

```
职位列表页（搜索结果页 / 推荐页的求职期望方向 tab）
    ↓ 点「开始」：记录当前方向 tab 与城市（页面城市 / 方向名括号城市）
    ↓ 扫描当前已加载职位卡片
    ↓ 按关键词 / 屏蔽词 / 屏蔽公司 / 城市筛选，匹配项入队
    ↓ 队列有匹配 → 随机等待后逐个投递
职位详情页
    ↓ 点击「立即沟通」（如有「继续沟通」确认框先确认）
聊天页
    ↓ 定位输入框 div#chat-input
    ↓ 填写招呼语（占位符替换）
    ↓ 点击发送 / Enter 回车
    ↓ 以「输入框被清空」判定发送成功
    ↓ 记录已发送（跨会话去重）
    ↓ 整页返回列表 → 自动点击切回开始时的方向 tab
    ↓ 队列还有就继续；当前职位投完则自动下滑加载该方向更多职位
    ↓ 直到本轮上限 / 该方向全部加载完且无更多匹配
```

## 常见问题

**Q：面板没出现？**
A：请确认已登录 BOSS 直聘，且当前在职位列表页（URL 含 `/web/geek/job`）。扩展只在 zhipin.com 域名下注入；更新扩展后需刷新已打开的 BOSS 标签页。

**Q：发送完回到了推荐页 / 方向丢失？**
A：请使用 v1.5.3 及以上版本，并在点「开始」前先选好顶部的求职期望方向 tab（如 `Java(珠海)`）。脚本会记录该方向，发送返回后自动切回。

**Q：为什么投了外地岗位 / 城市筛选不生效？**
A：这是 v1.5.4 之前的一个缺陷（城市占位「城市」被误判），请升级到 v1.5.4+；升级后仍异常时，可在面板「限定地区」手动填写城市名（如 `珠海`）强制锁定。

**Q：一个方向刷到几百个职位，为什么没投几个就停了？**
A：方向页是平台推荐流，包含大量与关键词无关或外地的岗位，符合「关键词 + 城市」的岗位可能本来就很少；脚本会在日志中提示已加载总数与匹配数。可适当放宽关键词、切换相邻城市或换一个方向 tab。

**Q：聊天页不输入招呼语？**
A：BOSS 聊天输入框为 `div#chat-input[contenteditable]`，发送按钮为 `button.btn-send`（也支持 Enter）。如页面结构变更请提 Issue 附截图。
