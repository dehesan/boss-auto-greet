# BOSS 直聘 · 定向自动沟通助手

> 求职端（非招聘端）浏览器扩展：按关键词筛选岗位，自动逐个进入职位详情发起沟通、发送自定义招呼语，发送完返回原始筛选列表继续。

仅用于个人求职，模拟真人操作流程，内置随机延迟与去重，降低风控风险。**请勿高频使用，账号安全与使用后果由使用者自行承担。**

---

## 功能特性

- **关键词筛选**：职位名称需包含任一关键词才处理（中英文逗号均可，不区分大小写）
- **屏蔽关键词职务**：职位名称含任一屏蔽词即跳过（如外包、驻场、外派、资深、高级、实习、应届）
- **屏蔽指定公司**：公司名含任一关键词即跳过
- **限定地区**：自动读取页面所选城市（如珠海），只与该城市岗位沟通，自动跳过混排进来的外地岗位；也可在面板手动指定多个城市
- **自定义招呼语**：支持 `{jobName}` `{company}` `{salary}` 占位符，自动替换为当前岗位信息
- **整页投完再翻页**：当前页匹配项一次性入队，全部处理完才翻页，不会投一个就刷新漏掉其余
- **自动去重**：已发送的岗位跨会话记录，不会重复沟通
- **返回原始筛选页**：发送完成后回到你点「开始」时的筛选列表（含城市、职位方向），并刷新出新职位
- **随机间隔**：每个岗位之间随机等待，可配置最小/最大秒数（最低 1 秒）
- **本轮上限**：可设置单次运行最多沟通多少个岗位
- **配置本地保存**：面板输入实时存入浏览器，关闭重开不丢失
- **日志面板**：保留最近 20 行运行日志，便于调试

## 安装方法（Edge / Chrome）

本项目为 Manifest V3 浏览器扩展，需以「加载解压缩的扩展」方式安装。

### Edge

1. 打开 Edge，地址栏输入 `edge://extensions` 回车
2. 左下角打开「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择本项目下的 **`extension`** 文件夹（包含 `manifest.json` 的那一层）
5. 扩展出现在列表中即安装成功

### Chrome

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目下的 **`extension`** 文件夹

## 使用方法

1. **登录 BOSS 直聘**网页版（`https://www.zhipin.com`）
2. **搜索你想投的职位方向**（如「大模型算法」），并选好城市、筛选条件，进入搜索结果列表页
   - 页面右下角会出现「BOSS 自动沟通助手」悬浮面板
3. 在面板中配置：
   - **关键词**：职位名称需包含的词，逗号分隔
   - **屏蔽关键词**：不想投的职位类型
   - **屏蔽公司**：不想投的公司
   - **限定地区**：留空会自动只投你在页面上选的城市；也可手动填，如 `珠海` 或 `珠海,中山`
   - **招呼语**：要发送的内容，可用占位符
   - **本轮上限**：本次最多沟通多少个
   - **间隔**：每个岗位之间随机等待秒数
4. 点击「开始」，脚本自动运行：
   - 扫描当前页 → 筛选匹配岗位 → 逐个进入详情 → 点「立即沟通」→ 聊天页自动填写并发送招呼语 → 返回原始筛选列表 → 下一个
5. 可随时点「暂停」或「停止」

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 关键词 | 职位名称含任一即匹配，中英文逗号均可 | `java` |
| 屏蔽关键词 | 职位名称含任一即跳过 | `外包,驻场,外派,资深,高级,实习,应届` |
| 屏蔽公司 | 公司名含任一即跳过 | 空 |
| 限定地区 | 只投这些城市，留空=自动只投页面所选城市 | 空（自动） |
| 招呼语 | 支持 `{jobName}` `{company}` `{salary}` | 见下 |
| 本轮上限 | 单次运行最多沟通数 | 30 |
| 最小间隔 | 岗位间最小等待秒数 | 8 |
| 最大间隔 | 岗位间最大等待秒数 | 15 |
| 最多翻页 | 自动翻页页数 | 3 |

**默认招呼语**：
```
您好！我看到贵司在招 {jobName}，我对这个岗位非常感兴趣，有相关的项目经验，希望有机会和您进一步沟通。
```

**占位符说明**：
- `{jobName}` → 当前职位名称（如「大模型算法工程师」）
- `{company}` → 公司名称
- `{salary}` → 薪资范围

## 工作流程

```
搜索结果列表页
    ↓ 扫描当前页职位卡片
    ↓ 按关键词/屏蔽词/屏蔽公司/薪资筛选
    ↓ 匹配项一次性入队（整页投完再翻页）
    ↓ 随机等待
职位详情页
    ↓ 点击「立即沟通」
聊天页
    ↓ 定位输入框 div#chat-input
    ↓ 填写招呼语（占位符替换）
    ↓ 点击发送 / Enter 回车
    ↓ 以「输入框被清空」判定发送成功
    ↓ 记录已发送（去重）
    ↓ 返回原始筛选列表页（带时间戳刷新）
    ↓ 处理队列下一个
```

## 常见问题

**Q：面板没出现？**
A：请确认已登录 BOSS 直聘，且当前在搜索结果列表页（URL 含 `/web/geek/job`）。扩展只在 zhipin.com 域名下注入。

**Q：点开始后提示「请先到职位搜索结果页」？**
A：请先在 BOSS 顶部搜索框搜索职位关键词，进入搜索结果列表后再点开始。

**Q：发送完回到了推荐页而不是我筛选的列表？**
A：请升级到 v1.5.1 及以上版本，该版本会在开始时记录完整筛选 URL（含城市+职位方向），发送完返回原页面并刷新。

**Q：聊天页不输入招呼语？**
A：BOSS 聊天输入框为 `div#chat-input[contenteditable]`，如页面结构变更请提 Issue 附截图。
